# Infrastructure

## Components

- Vercel: Next.js web application.
- Render: Express API service.
- Supabase: Auth, Postgres, Storage, pgvector.
- Gemini: embeddings and answer generation.

## Estimated MVP Costs

Costs depend on usage. Expect free or low-tier Vercel/Render/Supabase during development, plus Gemini usage-based billing. Review vendor pricing before production launch.
