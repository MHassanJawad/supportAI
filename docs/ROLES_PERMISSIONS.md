# Roles and Permissions

| Role | Permissions |
| --- | --- |
| Owner | Manage business, documents, FAQs, conversations, analytics, and members. |
| Admin | Manage documents, FAQs, conversations, and analytics. |
| Member | View dashboard data and conversations. |

MVP creates the first business creator as `owner`. Fine-grained route enforcement for admin/member differences is a phase-two hardening item; tenant membership enforcement exists in the MVP.
